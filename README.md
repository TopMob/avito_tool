# Avito Parser

Браузерное расширение (Chrome Extension, Manifest V3) для быстрого сбора и экспорта объявлений с Авито в структурированные форматы (Markdown, JSON, TSV) для последующего анализа через ИИ (ChatGPT, Claude, DeepSeek и др.) или в таблицах.

## Возможности

- **Быстрый парсинг**: сбор данных через `__NEXT_DATA__` страницы с добором недостающих полей из DOM.
- **Интерфейс в странице**: плавающая кнопка (FAB) и выдвижная панель прямо на странице поиска Авито, а также управление через иконку расширения.
- **Подгрузка страниц**: возможность загрузить следующие страницы или все страницы выдачи сразу.
- **Фильтры и сортировка**:
  - Фильтр по наличию Авито Доставки;
  - Скрытие зарезервированных товаров;
  - Поиск по ключевым словам и исключающим словам;
  - Сортировка по цене.
- **Настройка полей**: выбор нужных колонок (заголовок, цена, описание, доставка, ссылка, продавец, дата и др.).
- **Экспорт в 1 клик**: копирование в буфер обмена в форматах:
  - **Markdown** (с готовым системным промптом для ИИ);
  - **JSON**;
  - **TSV** (для вставки в Excel / Google Таблицы).
- **Темы оформления**: поддержка светлой и тёмной темы.

## Установка

1. Склонируйте репозиторий или скачайте архив с кодом:
   ```bash
   git clone https://github.com/TopMob/avito_tool.git
   ```
2. Откройте Google Chrome (или любой Chromium-браузер) и перейдите по адресу:
   ```text
   chrome://extensions/
   ```
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.
5. Выберите папку с проектом (`avito_tool`).

## Использование

1. Откройте любую страницу поиска или категорию на [avito.ru](https://www.avito.ru).
2. Нажмите на плавающую кнопку в правом нижнем углу или кликните по иконке расширения на панели браузера.
3. Настройте нужные поля, фильтры и выберите формат (Markdown / JSON / TSV).
4. Нажмите «Копировать» и отправьте данные в диалог с нейросетью.

```text
├── background/
│   └── service-worker.js    # Фоновый сервис-воркер
├── content/
│   ├── content.js           # Логика панели и взаимодействия со страницей
│   └── content.css          # Стили встроенной панели и FAB-кнопки
├── popup/
│   ├── popup.html           # Всплывающее окно по клику на иконку
│   ├── popup.js             # Логика всплывающего окна
│   └── popup.css            # Стили всплывающего окна
├── shared/
│   └── parser.js            # Модуль парсинга данных с Авито
└── icons/                   # Иконки расширения (16x16, 48x48, 128x128)
```
